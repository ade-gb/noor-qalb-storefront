# Noor Qalb storefront

A responsive jewelry storefront concept for Noor Qalb, built with semantic HTML, CSS, vanilla JavaScript, and GSAP 3. The supplied product and campaign photography is stored locally in `images/`.

## Run locally

Open `index.html` directly or serve this folder with a local web server. Google Fonts and GSAP load from their CDNs, so those assets need an internet connection.

## Interactions

- Category filtering and product search
- Quick-add shopping bag drawer with subtotal
- Mobile navigation and search overlay
- Newsletter form feedback
- GSAP hero sequence, scroll reveals, image parallax, product hover motion, and animated bag feedback
- Reduced-motion support

## Deployment

GitHub Pages deployment is configured in `.github/workflows/pages.yml` and runs on every push to `main`. The source repository is intended to remain private while the website is publicly accessible, where the GitHub plan permits Pages for private repositories.

Product names and prices are visual sample content pending the brand’s final catalog. Checkout and newsletter signup are prototypes and are not connected to commerce or email platforms.
